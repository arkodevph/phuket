# Website fonts

Latin WOFF2 subsets of DM Mono (400/500), Instrument Serif (regular/italic) and Manrope (variable 200–800), downloaded from the official Google Fonts distribution on 11 October 2026. They are served from this website; visitors do not make requests to Google Fonts.

The original families are maintained in [google/fonts](https://github.com/google/fonts/tree/main/ofl). Each family's SIL Open Font License is included alongside the font files as `dmmono-OFL.txt`, `instrumentserif-OFL.txt` and `manrope-OFL.txt`. No font outlines or family names were modified.
